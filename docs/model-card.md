# ncp-smol-360m: Next Concept Prediction on SmolLM2-360M

Independent small-scale reproduction of Next Concept Prediction (ConceptLM) on
`HuggingFaceTB/SmolLM2-360M`. The model keeps ordinary next-token generation and adds a
causal, product-quantized concept path over 4-token chunks: token states are pooled into
concepts, product-quantized, processed by causal concept blocks, and the predicted next
concept is fed back into the token decoder.

## TL;DR — what this checkpoint shows

This checkpoint comes from a token-matched comparison against the unchanged SmolLM2-360M
backbone: both arms consumed exactly 999,948,288 tokens of the same packed FineWeb-Edu
cache, in the same order, from the same initialization, with no restarts and no NaNs.
Combined tracked compute for both arms: about $55.

- **Token loss is neutral**: held-out NTP loss 2.5142 versus 2.5135 for the NTP-only arm
  (+0.03%, within run noise).
- **The concept channel is causally used**: zeroing predicted concept feedback at
  inference costs +0.1050 nats (+4.2% perplexity).
- **The codebook is rich**: effective perplexity 7.55 with 85.6% usage, grown
  monotonically from 2.93/74.8% at 100M tokens — no low-entropy shortcut.
- **The use is sequence-generic**: replacing feedback with another sequence's feedback
  from the same batch costs only +0.0008.

This mirrors the original paper's own ablation structure, where `L_ntp` paired with a
single auxiliary loss underperforms pure NTP and only the full loss triple wins at
8–300B-token training scales.

Intervention deltas are increases in held-out NTP loss relative to normal predicted
concept feedback, evaluated on identical held-out batches (fixed seed), the same batches
the baseline arm was evaluated on.

## Architecture

- chunk size: 4 tokens
- product code: 15 segments x 64 entries
- causal concept blocks: 2
- injection point: before token decoder block 2
- NCP target: next continuous concept
- loss: `L_ntp + 1 L_ncp + 1 L_vq`
- total parameters: 382.7M (361.8M backbone + 20.8M concept path)

This is a compact ConceptLM-style implementation, not an 8.9B NCP-ArchPreview replica. It
omits iterative residual coding, cross-scale residual connections, and the large-scale
training recipe.

## Training

FineWeb-Edu continued pretraining from `HuggingFaceTB/SmolLM2-360M` (revision `f8027fd0`):
1.0B packed train tokens plus a 10M held-out split, both SHA256-pinned; sequence length
1024; 131,072 tokens per step; 7,629 steps; LR 3e-5 with cosine decay to 10%; a single
uninterrupted A100-40GB container (11.05 h).

## Intended use and limitations

A research artifact for studying latent concept channels in small language models — not a
production text generator. The SmolLM2 tokenizer and generation API are unchanged;
quality and safety limitations of the base model carry over. One seed per arm; 1B tokens
is far below the scales where the original paper reports gains; the concept path uses the
continuous target variant (the discrete selected-code variant is gated on codeword
normalization).
